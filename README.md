# OpsDesk – IT Operations Platform

OpsDesk is a C# and .NET-based IT Operations Platform project designed to demonstrate basic IT operations workflows, employee access control, and incident management.

## Features

- Engineer welcome dashboard
- Employee experience classification
- Employee activity and access control
- Incident ticket creation
- Critical priority alerts
- Incident status management
- Multiple incident tracking
- Incident count summary

## Technologies Used

- C#
- .NET 8
- Visual Studio Code
- Ubuntu Linux
- Git and GitHub

## Run Locally

Clone the repository:

```bash
git clone git@github.com:arbaz186186-cmyk/opsdesk.git
cd opsdesk
```

Run the application:

```bash
dotnet run
```
